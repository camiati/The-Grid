## Frameworks

| Framework | Covers |
|---|---|
| [CMMC](./CMMC/) | DoD's program for verifying contractor protection of FCI and CUI |

| [NIST SP 800-171](./NIST%20SP%20800-171/) | The CUI security requirements behind DFARS 7012 and CMMC Level 2 |
| [SOC 2](./SOC%202/) | AICPA attestation on a service organization's security controls |
