# FedRAMP Rev5

The legacy FedRAMP path: NIST SP 800-53 Rev. 5 baselines, a narrative security package, a third-party assessment, and usually an agency sponsor. 
Still active, and still the path DoD accepts for cloud services handling CUI.

*Last reviewed October 2026.*

## Status

| Item | Detail |
|---|---|
| Governing&nbsp;rules | Consolidated Rules for 2026, mandatory for existing Rev5 certifications on January 1, 2027 |
| New&nbsp;applications | Accepted until June 11, 2027 |
| End&nbsp;of&nbsp;Rev5 | Rev5 certification status is expected to end by December 31, 2028 |
| Class&nbsp;D | Rev5 is currently the only path to Class D (formerly High) |

## Practitioner notes

**It's still the DoD standard.**
- The DoD FedRAMP Moderate equivalency memo is defined against the Rev5 Moderate baseline.
- For cloud services holding CUI under DFARS 7012, Rev5 Moderate (or equivalency) is what's accepted today.

**Rev5 changed too.** 
- The Consolidated Rules apply to existing Rev5 certifications, including machine-readable package requirements.
- Holding a Rev5 certification doesn't mean nothing changes.

**Plan the move to 20x now.** 
- New Rev5 applications stop in June 2027, and Rev5 status is expected to end by the close of 2028.

**Agency sponsorship is still the norm.**
- Rev5 Classes B, C, and D go through the Agency Certification path.
- Program Certification without a sponsor is limited for Rev5.

**Old templates live on the legacy page.** 
- Pre-2026 FedRAMP documents and templates have moved to fedramp.gov/legacy.
